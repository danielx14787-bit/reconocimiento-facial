Servicios Principales

Módulos de Seguridad y Reconocimiento

Componentes requeridos en la Guía SENA desarrollados con clases utilitarias de Tailwind CSS.

Módulo 01

Detección Facial

Identifica rostros en tiempo real con alta precisión. Procesa múltiples ángulos faciales instantáneamente garantizando la identidad de los usuarios.

  • Mapeo 3D de 68 puntos geométricos faciales.
  • Resistente a cambios de iluminación, gafas y vello facial.
  • Soporte para video en vivo (Cámaras IP / Webcams).
Módulo 02

Seguridad Inteligente

Protege tu información con tecnología avanzada y encriptación de extremo a extremo para asegurar la privacidad biométrica sin almacenar fotografías directas.

  • Vectores numéricos hash irreversibles (Zero-Knowledge).
  • Cumplimiento estricto con normativas GDPR y Habeas Data.
  • Auditoría de accesos y alertas preventivas en tiempo real.

Guía para Publicar en GitHub Pages

Pasos exactos para desplegar y obtener tu enlace público

1. Crear el repositorio en GitHub:

Crea un nuevo repositorio público llamado reconocimiento-facial-tailwind.

2. Subir este archivo como index.html:

Guarda este archivo con el nombre exacto de index.html en la raíz de tu repositorio.

3. Activar GitHub Pages:

Dirígete a Settings > Pages en tu repositorio. En Branch selecciona main (o master) y la carpeta / (root). Haz clic en Save.

Tu URL resultante para la entrega será:

https://<tu-usuario>.github.io/reconocimiento-facial-tailwind/

Nota de Privacidad y Ética

Esta aplicación es un proyecto educativo desarrollado para fines de formación técnica en el SENA.

Privacidad garantizada: No solicita acceso a hardware de cámara web real, no recopila imágenes de personas y no procesa datos biométricos sensibles de usuarios externos.

Todo el funcionamiento visual se realiza mediante simulaciones vectoriales y clases utilitarias de Tailwind CSS.
